## Where it must not be trusted

* **Read length.** The sweep ran on 101 bp reads. `read_len` is a feature,
  but no dataset in the corpus is 150 bp, so a rule that splits on it is
  extrapolating. `--print-args` shows the rule; a 150 bp NovaSeq library should
  not trust a `read_len < 110` leaf.
* **Chemistry.** The corpus has no 2-colour (NovaSeq/NextSeq) library, so the
  high-quality 5' polyG head case is not represented. `--head-dropout` is not
  an axis of this model at all.
* **Long low-quality 3' tails.** The corpus's longest injected 3' tail is 20 bp,
  so the long-tail regime is unlearned.
* **The length floor.** Every rule's `min_len` comes from the Phase D grid,
  which ran at 0.9L-era floors. D-18 moved the shipped floor to 0.67L after
  the sweep, so applying a recommendation REPLACES that floor; pass `--min-len`
  explicitly (an explicit flag always wins) to keep the 0.67L budget.
* **Orientation.** 13 configs of the sweep exploited a bench-only R2 reverse;
  the model cannot reproduce that effect, and it is not a fastprep flag.
* **Domain coverage:** bacterial_isolate, generalised, human_gut, metagenomics, rna_seq, virome — a study type outside
  these six is extrapolation, and the LODO table above is the measurement of how
  bad that gets.
